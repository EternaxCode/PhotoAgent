PhotoAgent

흔들린 사진은 자동으로 걸러내고, 잘 나온 사진만 예쁘게 보정해서
새 폴더에 저장해 주는 사진 정리 프로그램

🍎

Mac 용 받기

macOS 14 (Sonoma) 이상
⬇ DMG 다운로드
  1. 내려받은 DMG 파일을 열기
  2. PhotoAgent 를 응용 프로그램 폴더로 드래그
  3. 처음 한 번만 앱을 우클릭 → 열기
    ("확인되지 않은 개발자" 경고 통과)
🪟

Windows 용 받기

Windows 10 / 11
⬇ ZIP 다운로드
  1. 내려받은 ZIP 압축 풀기
  2. 설치.bat 더블클릭 (자동 설치)
  3. 바탕화면의 PhotoAgent 더블클릭으로 실행
🔒 원본 사진은 절대 바뀌지 않아요. 결과는 원래 폴더 옆에 “폴더이름_결과” 라는 새 폴더로 저장됩니다.

무엇을 해 주나요?

🔍
흔들린 사진 자동 감지 일부러 배경을 흐리게 찍은 사진(아웃포커싱)과 실제로 흔들린 사진을 구별합니다.
✨
자동 보정 밝기·색감·선명도를 자동으로 다듬어 저장합니다. 촬영 정보(EXIF)도 유지돼요.
✍️
워터마크 이름이나 로고를 원하는 위치·크기·글씨체로 넣을 수 있어요. 전체 또는 사진별 선택 적용.
📐
크기·형식 선택 저장할 사진 크기(원본~작게)와 파일 형식(JPG/PNG 등)을 고를 수 있습니다.
🎛️
전문 편집 (Mac) 노출·색상·디테일 슬라이더, 히스토그램, 피사체/배경 분리 보정, 배경 흐림 효과.
🖱️
쉬운 사용법 폴더 고르기 → 확인 → 저장, 3단계면 끝. 컴퓨터가 익숙하지 않아도 괜찮아요.
